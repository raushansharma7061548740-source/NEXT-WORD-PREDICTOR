# 🚀 Next Word Prediction using LSTM

An AI-powered Next Word Prediction application built using Deep Learning, NLP, TensorFlow, and Streamlit. 
The model predicts the most probable next word from a given text sequence using an LSTM Neural Network.

## 🔗 Live Demo
[[Streamlit App](YOUR_STREAMLIT_LINK_HERE)](https://next-word-predictor-kbbtcnffdh6pksef84o43n.streamlit.app/)

## 🧠 Tech Stack
- Python
- TensorFlow / Keras
- NLP
- LSTM
- Streamlit

## ⚙️ Features
- Real-time Next Word Prediction
- Deep Learning based NLP model
- Interactive Streamlit UI
- Sequence Tokenization & Padding
- Deployable Web Application

pip install -r requirements.txt  
streamlit run app.py
